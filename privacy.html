CUPAS BOT

개인정보처리방침

시행일: 2026년 7월 29일

1. 기본 원칙

CUPAS BOT 운영자(이하 “운영자”)는 서비스 제공에 필요한 최소한의 정보만 처리하며, 사용자의 개인정보를 판매하지 않습니다. CUPAS BOT은 사용자의 Windows PC에서 실행되는 데스크톱 프로그램으로, 주요 계정 인증정보와 설정은 사용자의 PC에 저장됩니다.

2. 처리하는 정보

라이선스 및 운영 정보

  • 라이선스 키, 구매자 이메일(발급 시 입력한 경우), 라이선스 상태 및 만료일
  • Discord 서버·채널·봇 사용자 식별자
  • 인스턴스 식별자, 장치 해시, 최근 실행 확인 시각

사용자 PC에 저장되는 정보

  • Discord 봇 토큰, Coupang Partners API 키, OpenAI API 키(선택 사용)
  • Meta Threads 앱 정보와 OAuth 액세스 토큰
  • 사용자가 입력한 프록시, 템플릿, 예약 게시 정보 및 모니터링 설정

위 인증정보는 사용자가 선택한 외부 서비스 API 호출에 사용되며, 운영자의 라이선스 서버에 저장하지 않습니다.

Threads 모니터링 정보

  • 사용자가 지정한 공개 Threads 사용자 이름
  • 공개 게시물의 식별자, 내용, 게시 시각, 미디어 및 고유 링크
  • 중복 알림 방지를 위한 최근 확인 상태

3. 이용 목적

  • 정상 라이선스 확인, 동시 실행 제한 및 서버 바인딩
  • Discord와 Threads 계정 연결, 게시·삭제·예약·인사이트 기능 제공
  • 사용자가 지정한 공개 Threads 계정의 새 게시물 알림
  • Coupang Partners 링크 변환 및 상품 정보 정리
  • 오류 진단, 부정 이용 방지 및 고객 지원

4. 외부 서비스

기능 사용 과정에서 다음 서비스로 정보가 전송될 수 있으며, 각 서비스의 정책이 함께 적용됩니다.

  • Meta Threads API: 계정 인증, 게시물 처리, 공개 프로필 및 게시물 조회
  • Discord: 명령 실행, 결과 메시지 및 웹훅 알림
  • Supabase: 라이선스와 인스턴스 상태 관리
  • OpenAI API: 사용자가 활성화한 경우 카카오톡 원문 분석
  • Coupang Partners API: 상품 링크 변환 및 제휴 기능

5. 보관 및 파기

  • 로컬 인증정보와 설정은 사용자가 삭제하거나 프로그램 폴더를 제거할 때까지 사용자의 PC에 보관됩니다.
  • 활성 인스턴스 정보는 프로그램 종료 또는 서버의 비활성 정리 절차에 따라 해제됩니다.
  • 라이선스 기록은 계약 이행, 고객 지원 및 부정 이용 방지를 위해 필요한 기간 동안 보관한 후 파기합니다.
  • 법령상 보관 의무가 있는 경우 해당 기간 동안 분리하여 보관할 수 있습니다.

6. 사용자의 권리와 삭제 요청

사용자는 Discord의 /계정삭제 및 /리셋 명령으로 Threads 연동과 서버 바인딩을 삭제할 수 있습니다. 자세한 절차는 사용자 데이터 삭제 안내를 확인하세요.

7. 보호 조치

운영자는 인증정보가 Discord 메시지, 콘솔 로그 및 오류 로그에 평문으로 노출되지 않도록 마스킹하고, 라이선스 관리 권한과 구매자 권한을 분리합니다. 사용자는 설정 파일과 토큰을 제3자에게 공유하지 않아야 합니다.
